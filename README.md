The plain-text file contains one domain per line, sorted alphabetically.

## Snapshot

- 595,745 unique available domains
- 376,755 domains containing one digit
- 190,571 domains containing two digits
- 28,416 domains containing three digits
- Lowercase `a-z` and digits `0-9`
- `.com` top-level domain

The source scan produced 595,949 rows. This published dataset removes 204 duplicate rows while preserving every unique result.

Because this snapshot was collected on August 21, 2026, some listed domains may now be registered and unavailable. Verify a domain with a registrar before relying on this dataset.
